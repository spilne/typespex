# `@typespex/mcp-server`

Typed server primitives for MCP applications generated by `@typespex/mcp-emitter`.

The package adapts generated JSON Schemas and TypeSpex codecs to MCP SDK tools and provides typed
handlers, contexts, middleware, rich results, error classification, and server factories. It does
not include transports, framework adapters, or HTTP bridge execution.

## Entry points

- `@typespex/mcp-server` exports `McpToolDefinition`, `McpServerDefinition`, `Schema`,
  `SchemaDocument`, `createSchema`, `createSchemaDocument`, `createMcpServer`, typed applications
  and contexts, middleware, and result helpers.

The `@typespex/mcp-server/internal` subpath contains the execution seam used by protocol bridges.
Application code should not import it.

## Runtime requirements

The package is ESM, targets ES2022, supports Node.js `>=22.12 <23` or `>=24 <25`, and requires the
MCP SDK v2 server package.
